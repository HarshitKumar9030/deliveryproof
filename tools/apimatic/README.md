# APIMatic development integration

APIMatic's PayPal Context Plugin supplies PayPal API context to supported coding tools. It is not a payment gateway or an application-runtime service.

Use the installation/resource link on the [hackathon sponsor page](https://paypalaihackathon.devpost.com/details/apimatic) for your coding tool. Do not invent an APIMatic runtime endpoint or add unnecessary credentials to this app.

After installation, use it to check PayPal request/response shapes and evidence constraints while implementing the adapter. Record actual usage in the hackathon submission. The plugin has not been installed or claimed by this scaffold.
